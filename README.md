# VPS 管家

私人服务器资产管理台。原生 HTML/CSS/JavaScript 界面，Node.js 后端；运行时无需第三方 npm 包。

本仓库保存当前界面及完整功能源码，不包含任何生产账号、服务器资料、Telegram 凭据、加密资料库、密钥、证书或备份。

## 功能

- 浅色玻璃界面（Glass Dock）：顶部全局搜索，底部玻璃程序坞导航；深色模式跟随系统，也可在设置里固定浅色或深色。
- 总览以卡片网格展示每月开销、服务器状态分布、最近一次续费和 30 天内续费；服务器页有卡片、列表、服务商三种视图，可按置顶、到期、月付或名称排序，支持多选后批量改状态、开关 TG 提醒、调整费用统计或删除。
- 服务器详情与编辑从侧边滑出，分连接、账单、资料、域名与备注四个标签；未保存的编辑在关闭前会确认。
- 页面在前台且近期有操作时，每分钟同步其他页面或设备的修改；正在填写表单时不打断，空闲会话仍按时过期。
- SSH、服务商控制台及面板账号与对应密码成组展示；登录后按需查看或直接复制密码，离开页面或超时清空显示。
- 首页月付、年付及资产金额统计，可选择参与统计的服务器；「费用」页另有自定义组合、按服务商折合月付和参考汇率。
- 续费记录、到期日期计算与历史记录；指令库只保存与复制内容，不执行远程命令。
- Telegram 到期提醒：逐机选择，到期前 7 天、前 1 天和当天各通知一次；北京时间 09:00 后检查，符合条件的漏发可在到期前补发。
- 提醒选择弹窗，确定后发送选择确认；向机器人私聊发送 `检查`、`到期 30`、`开销` 或 `帮助`，得到适合手机阅读的清单。
- 到期提醒附「✅ 已续费」按钮，二次确认后记录续费 1 期并更新到期日。
- 每日自动加密备份保留最近 7 个北京时间日期；手动备份与恢复前备份各保留 30 份，恢复需先预览。
- 管理员登录、scrypt 密码哈希、TOTP 双重验证、一次性恢复码；资料库使用 AES-256-GCM 加密。
- CSRF/Origin 校验、会话失效保护、版本冲突处理；健康检查、监督进程与可选 systemd 开机自启。

## 运行环境

Linux、Node.js 24 或更新版本、Bash、`flock`。初始化脚本以 root 执行，应用读取配置后切换到数字 UID/GID `62031`。目录和 systemd 模板以 `/root/VPS` 为部署位置；换目录时需要调整服务单元中的绝对路径，并保证服务身份能访问运行目录。

## 全新部署

在空的部署目录准备源码后执行：

```bash
cd /root/VPS
mkdir -p tmp .cache
node bin/init.mjs
bash bin/start.sh
```

初始化会生成独立密钥、一次性设置令牌和空资料库；已有配置时拒绝覆盖。默认仅监听 `http://127.0.0.1:8787`，用于本机访问或受控隧道调试。首次设置令牌位于 `.private/setup-token`，在首次打开页面时填写并设置独立管理员账号；不要把该令牌或主密钥提交到 Git。

公开访问前，先停服务，配置 HTTPS 入口与 `.private/config.json`，再启动。全新环境需要自行准备证书与反向代理，源码不附带现有服务器的部署状态或证书。

```bash
bash bin/stop.sh
# 完成 HTTPS 配置后
bash bin/start.sh
```

配置关键字段：

| 字段 | 用途 |
| --- | --- |
| `mode` | `private` 是仅回环调试模式；HTTPS 正式部署设置为 `public` |
| `origin` | 浏览器访问的完整 HTTPS 来源，例如 `https://vps.example.com` |
| `host` / `port` | 应用监听地址和端口；非回环监听必须启用 TLS |
| `tls.key` / `tls.cert` | 项目 `.private/tls/` 内的后端私钥和证书路径 |
| `trustedProxies` | 明确可信的代理来源 IP；只信任其单值 `X-Real-IP` |
| `key` / `setupHash` | 初始化生成的密钥与设置令牌摘要；保留原值 |
| `serviceUID` / `serviceGID` | 初始化默认使用 `62031` |

监督器的 HTTPS 检查读取 `.private/tls/ca.crt` 并验证回环地址 `127.0.0.1`；后端证书必须包含 `IP:127.0.0.1` SAN，且由该 CA 签发。如果反向代理使用 `vps-internal` 验证后端证书，还需包含对应的 DNS SAN。代理应保留正确的 Host，并验证后端证书。公网证书与内部证书续期由部署者配置。

`deploy/vps-workspace.service` 是可选的系统服务模板。登记前核对 Node 路径和工作目录；系统服务登记属于系统级操作。登记后启动、停止仍使用项目内的 `bin/start.sh`、`bin/stop.sh`。

## Telegram

在「系统设置 → Telegram 到期提醒」填写自己的 Bot Token 和正数私聊 Chat ID，并先与机器人发起会话。在选择弹窗勾选需要提醒的机器，填写有效续费日期，再开启自动提醒。

程序每 5 分钟检查；北京时间 09:00 后，对剩余 0–7 天的机器按三个提醒时点（剩余 7–2 天、剩余 1 天、到期当天）各发送一次；错过的时点不补发，只发送当前时点的提醒，过期或无有效日期的记录不自动发送。发送状态与去重记录加密保存；不能确认送达的消息不会自动重复发送。

私聊 `检查` 或 `/check` 只响应配置 Chat ID 对应本人，忽略群聊、其他账号、转发和编辑消息。结果按已过期、7 天内到期、后续提醒、待补日期分组，每条最多 5 台，不包含 IP、账号或密码。自动提醒关闭时仍可查询；`private` 调试实例不启用真实查询轮询。

其他私聊指令：`到期 30` 或 `/due 30` 列出未来 N 天（1–365）到期的全部机器，含价格与自动续费；`开销` 或 `/cost` 汇总月付、年付、单期合计与各服务商折合月付；`帮助`、`/help` 或 `/start` 显示指令说明。

每条到期提醒带「✅ 已续费」按钮。点击后先显示确认按钮和将记录的金额，确认后按该机器的单期价格与付费周期记录续费 1 期，到期日顺延，并在原消息末尾注明。同一提醒只会记录一次；到期日已在别处修改、机器已删除或未填写价格时不做改动并提示。按钮只响应配置 Chat ID 本人的私聊。机器人不能同时被其他轮询客户端占用；程序不会删除已有 webhook。

## 数据与恢复

`.private/config.json` 中的主密钥和 `runtime/workspace.vault` 必须分别妥善保管。只有加密备份而没有原密钥，无法恢复资料。应用日志、运行状态在 `.private/`，备份在 `runtime/backups/`，这些内容全部被 Git 忽略。

网页恢复保留当前登录账号、双重验证与 Telegram 配置，恢复前先生成快照。需要完整灾难恢复时，停止服务后使用：

```bash
bash bin/stop.sh
node bin/restore.mjs runtime/backups/选定备份.vpsvault
bash bin/start.sh
```

完整恢复也会恢复备份中的账号及双重验证状态。不要删除原密钥、把生产资料复制进测试环境，或向仓库提交任何 vault 文件。

## 测试

测试使用合成账号与独立资料库，不需要生产 Bot Token。集成测试需要 Linux/root 权限与 UID/GID 切换能力；请在独立源码副本中运行，避免占用生产服务测试端口。

```bash
mkdir -p runtime/backups tmp .cache
node --test --test-concurrency=1 tests/*.test.mjs
```

测试子进程会降权到 UID/GID `62031`。检出目录及其祖先必须允许该身份遍历，源码需可读，`runtime/` 需可遍历；各测试会为自己的临时数据目录设置独立属主。不要为此开放 `.private/`、认证文件或其它项目目录。

监督器的 HTTPS 测试需要测试副本中的 `.private/tls/ca.crt`、`server.crt`、`server.key`；使用自己生成的测试 CA，服务器证书包含 `DNS:vps-internal` 和 `IP:127.0.0.1` SAN。不要复制生产 TLS 私钥来运行测试。`VPS_TEST_TLS=1` 可启用 API 的 HTTPS 模式，此时需让测试客户端信任该测试 CA。

## 目录

- `public/`：页面（`index.html`）、界面（`app.js`）、可单独测试的纯函数（`core.js`）与样式（`styles.css`）。
- `server.mjs`：HTTP/HTTPS、认证和业务 API。
- `lib/`：费用、续费、加密备份、Telegram 与权限相关模块。
- `bin/`：初始化、启停、监督器、恢复及可选旧格式迁移工具。
- `deploy/`：可选 systemd 服务模板。
- `tests/`：业务、安全、前端行为与集成测试。

费用使用固定参考汇率，仅供预算估算；自动续费选项仅记录状态，不发起付款。指令库不执行代码，服务器记录也不代表实时连通性探测。
